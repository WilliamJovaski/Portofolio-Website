## Ukuran & Format Ideal

- Rasio potret **4:5** (mis. **800 × 1000 px**), format **JPG** atau **WebP** di bawah **500 KB**.
- Selama file foto belum ditaruh di folder ini, komponen `<Polaroid>` otomatis menampilkan placeholder gradient dari palet warna website tanpa error.
